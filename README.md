# Raphael Tagbo — Tech Solutions Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Included
- Responsive modern blue technology theme
- Profile photo
- About, services, projects, skills and contact sections
- Email and WhatsApp CTAs
- Mobile navigation
- SEO description and semantic HTML

## How to use
Open `index.html` in a browser to preview the portfolio.

## Publish free
You can deploy this folder using GitHub Pages, Netlify or Vercel.
Before publishing, update any placeholder social links and add a CV file if desired.
